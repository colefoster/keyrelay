Keyrelay gives your coding agent a local link where you can enter one key or several credentials in labeled fields. Review the command, send it once, and let the agent keep working. No account or API key needed to install.

From “don’t paste it”
to getting it done.

The key goes to the command.
The conversation keeps moving.

  1. 1

    Ask for a credential.

    The agent wraps its command with Keyrelay. A temporary local broker starts; the runner prints a link and waits.

  2. 2

    See what will run.

    Open the local link on the same computer. Review the command and enter the token in your browser.

  3. 3

    Send it once.

    The runner claims the credential, passes it through an environment variable or stdin, and runs the command.

Try it with a made-up value.

No account or real secret.
Runs entirely on your computer.

This demo runs a local Node.js command that confirms it received a value without printing it.

npx keyrelay run --env DEMO_TOKEN -- node -e "console.log(process.env.DEMO_TOKEN ? 'Handoff complete.' : 'No value received.')"
  1. Open the printed http://127.0.0.1:…/r/… link on the same computer.
  2. Review the command, enter demo-value, and select Send once.
  3. The terminal prints Handoff complete. and the temporary broker shuts down.

The link expires after five minutes. Ctrl+C cancels the handoff. Keyrelay prints the link rather than opening a browser.

Four credentials.
One form.

A separate box for each value.
No JSON to write by hand.

Connecting an app that needs an API key, a secret, and two access tokens? Your agent names each field. You paste each value into its own password box and select Send once.

npx keyrelay@latest run --env CREDENTIALS \
  --note "Use the app account. Enable write permissions first." \
  --field "apiKey=API Key" \
  --field-help "apiKey=Find this in your app's Keys and tokens settings." \
  --field "apiSecret=API Key Secret" \
  --field "accessToken=Access Token" \
  --field "accessTokenSecret=Access Token Secret" \
  -- your-command
  1. The private form shows four labeled password fields.
  2. Keyrelay builds the JSON object and delivers it to your command.
  3. Each credential is redacted if the command echoes its exact value.

Add --note for instructions above the form and --field-help NAME=Instructions for help under a field. Show or hide pasted values to check them; submitting clears and hides them again. Instructions are plain text: never include credentials. Replace your-command with a tool that accepts a JSON credential bundle in CREDENTIALS. This example requires Keyrelay 0.1.5 or newer on both the runner and any remote broker. This public page collects no credentials.

Your computer.
Your trust boundary.

Run one command. Keyrelay starts a temporary broker on your computer and shuts it down afterward. Tailscale is optional if you want to enter keys from another device.

Read the security model ↗
In memory
Requests expire after five minutes. Successful claims delete the entry; expired entries are cleared on the next request.
In your control
Bound to localhost. No database or HTTP request logging. Other programs on your computer share the same trust boundary.
Built on trust
Keyrelay keeps the handoff out of chat. A command still receives the real secret and can store or transmit it. Review what you run.

Questions

What do I need?

Node.js 18+ and Python 3.9+. No account, API key, server setup, or Tailscale is needed to install or try it.

Can I enter the key from my phone?

Not with the default local link; it opens only on the computer running the command. For another device, run your own broker behind Tailscale and pass its URL with --url. Tailscale setup ↗

Can I hand over several credentials at once?

Yes. Repeat --field NAME=Label for up to 16 required fields in one form. Keyrelay delivers a JSON object through the selected environment variable or standard input. Multi-credential setup ↗

Does Keyrelay make a command safe to run?

No. It is not a sandbox. The command receives the real credential and can store or send it. Review the command, and prefer narrowly scoped, short-lived credentials.

Does this website see my key?

No. This site collects no credentials. You enter the key in a form served by Keyrelay on your computer, or by your own Tailscale broker.
