# Keyrelay visual system

Extend the existing broker's midnight-blue and cyan identity. Flat, precise line work shows the credential route; oversized editorial typography carries the central promise. White text on midnight; cyan reserved for the handoff and primary action. No invented security claims.

The public landing surface persuades through a legible illustrative handoff, then concrete setup and an honest trust boundary. Mobile stacks the same reading order. Keyboard focus and reduced motion are first-class.
